# Bay Area Executive Limo Website

A polished responsive single-page limo / black-car company website ready for GitHub Pages.

## Upload to GitHub
Upload these files to the root of your repository:
- index.html
- style.css
- script.js
- images/ (optional; add your real photos later)

## Customize before launch
Search and replace:
- BAY AREA EXECUTIVE LIMO — your actual company name
- (415) 555-5555 — your phone
- info@example.com — your business email
- service area and fleet details — your actual information

The quote form is front-end only and opens the visitor's email application. For a real online booking database, connect a form backend later.
